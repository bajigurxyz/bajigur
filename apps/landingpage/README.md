# @bajigur/landingpage

The public marketing site for Bajigur: the pitch, and the copy-and-paste block
that wires an agent into the marketplace.

Static and wallet-free — everything that needs an account lives in
`@bajigur/web`.

Next.js 16 (App Router) · React 19 · Tailwind CSS v4 · React Compiler.

```bash
bun run dev --filter=@bajigur/landingpage     # http://localhost:3001
```

## Environment

| Variable | Purpose |
| --- | --- |
| `NEXT_PUBLIC_APP_URL` | Where Gallery / Connect / Start selling point, default `http://localhost:3000` |
